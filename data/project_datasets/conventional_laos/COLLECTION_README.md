## Provenance and use

The complete original-to-repository path mapping, file sizes and SHA-256 checksums are in `doc/project_handover/source_to_repository_manifest.csv`. Exact duplicates point to one preserved copy. Original bytes are unchanged. Code and data filenames in older notebooks may refer to their former locations. Use the restoration utility before attempting to run them, then set the notebook input/output paths.

Code descriptions, imported modules and literal file references are indexed in `code_version_catalogue.csv`. These are source inspections, not execution verification. Saved notebook conclusions may be superseded by `final_code/report_analysis`. Third-party code retains its source attribution/licence; inclusion does not imply team authorship.

For structured CSV headers see `dataset_schema_index.csv`. Original workbook sheets, native instrument metadata and source READMEs remain authoritative for units. Do not combine different cohorts or treat simulated event labels as measured clot times.
