# Member 3: step-up/down and transient analysis

This is a curated copy of the Member 3 notebook and output tables from the extracted `New folder.zip` handover bundle. The original ZIP and its extracted source remain preserved under `90_Archives/Mixed_Handover_Bundle/`.

The notebook analyzes standardized step data and records step verification, motor/rate settling, transient and stable windows, conventional step features, relaxation fits (including the scalar ethixo-EVP model), step-magnitude and matched-direction comparisons, and reliability/sensitivity summaries. It uses the primary windows `[rate settling, 2 s]` and `[30 s, end]`, with alternative boundaries checked as sensitivity analysis.

The archived output package contains 136 step-feature rows keyed by Member 3 IDs (`S001` etc.). The shared Member 1 feature table contains 138 eligible step rows keyed by the common measurement IDs (`P1M...`). The integration notebook maps the 136 Member 3 rows to the common IDs using workbook, sheet, block, and condition label; the two AUG18 records present only in the 138-row table are retained and identified.

The notebook is preserved as received and has not been rerun or modified. Its old local paths may no longer resolve after consolidation.
